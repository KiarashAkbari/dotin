# مرحلهٔ ۳ — مدل هزینه‌محور نکول

این پوشه فعلاً **فونداسیون** است: قراردادهای داده، منبع فایل از مسیر کارخانهٔ مرحلهٔ ۱،
ریاضیات هزینه و آستانه، ویژگی‌ها، و DDL نسخه‌دار. نوت‌بوک، آموزش مدل، و اعداد گزارش
بعد از رسیدن فایل داده و دسترسی به PostgreSQL نوشته می‌شوند؛ هیچ عددی اینجا ادعا نشده است.

## پیش‌نیازها (هر دو بیرونی‌اند)

1. **داده:** `cs-training.csv` از رقابت Kaggleٔ *Give Me Some Credit*. این یک competition است،
   نه dataset؛ باید قوانینش را با حساب خودتان بپذیرید. فایل را در
   `data/raw/cs-training.csv` بگذارید (در Git نمی‌رود). دیکشنری داده را هم بخوانید؛
   چند ستون معنایی دارند که از نامشان پیدا نیست.
2. **پایگاه‌داده:** همان سروری که مرحلهٔ ۲ روی آن بارگذاری شد. تنظیمات از
   `../stage-1-kiarash-akbari/config/default.toml` خوانده می‌شود و رمز از متغیر محیطی
   نام‌برده در `database.password_env` می‌آید.

## نصب

```bash
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m pip check
```

`requirements.txt` نسخه‌های مستقیم را قفل می‌کند؛ freeze کامل باید از محیطی ساخته شود که
اعداد گزارش را تولید کرده (دستور داخل همان فایل آمده است).

## تست‌های آفلاین

```bash
.venv/bin/python -m unittest discover -s tests -v
```

بدون اینترنت، بدون پایگاه‌داده، و بدون فایل Kaggle اجرا می‌شوند (دادهٔ مصنوعی با seed ثابت).
انتظار: `Ran 137 tests` و `OK`.

## DDL

```bash
psql "$DATABASE_URL" -f sql/010_credit_schema.sql
```

بدون `BEGIN/COMMIT` داخلی است، چون اعمال‌کنندهٔ مرحلهٔ ۲ خودش تراکنش را باز می‌کند.
دستور CLI داخل `data_factory` برای بارگذاری credit هنوز نوشته نشده (گام بعدی).
