# شواهدِ دادهٔ واقعی

این پوشه عمداً خالی است. `../fixture/` شواهدِ یک اجرایِ کنترل‌شده روی دادهٔ آزمایشی است
(ماشین‌افزار، نه نتیجهٔ چالش)؛ چیزی که اینجا باید بنشیند، خروجیِ **اجرای واقعی** است: همان
نوت‌بوک، روی `cs-training.csv`ِ خودِ Kaggle، روی PostgreSQLِ اجراکننده.

## چه چیزی کپی شود

```bash
cd stage-3
cp data/curated/credit_evidence.json docs/evidence/real/
cp data/curated/credit_run_manifest.json docs/evidence/real/
```

- `credit_evidence.json` تنها منبعِ عددهای `report.md` است: سلولِ آخرِ نوت‌بوک
  (`report.apply_to_file`) دقیقاً از همین payload پر می‌کند، پس هر عددی که در گزارش می‌خوانید
  باید در این فایل پیدا شود. آزمونِ `test_the_shipped_report_has_only_well_formed_slots`
  وقتی گزارش پر شده باشد، همین را می‌سنجد؛ پس اگر این فایل کنارِ گزارشِ پرشده نباشد، آن
  آزمون سبز نیست - و درست هم نیست که سبز باشد. و این کپی را commit کنید: `data/curated/` در
  cloneِ تازه خالی است، پس همین فایل تنها شاهدِ موجود برای عددهای گزارشِ commit‌شده است.
- `credit_run_manifest.json` می‌گوید این اجرا از کدام commit، با کدام sha256 از فایلِ ورودی،
  و با چه صفحه‌بندی‌ای ساخته شده. **دستی ویرایشش نکنید**: تنها راهِ درستِ عوض‌کردنش، اجرای
- یک ردیفِ evidence را نباید به‌عنوان نتیجهٔ holdout نقل کرد: `holdout.matrix_sensitivity`
  آستانه را روی همان ردیف‌های holdout دوباره انتخاب می‌کند، پس هزینه‌اش «بهترین حالتِ ممکن روی
  این ۳۰٬۰۰۰ ردیف» است نه «هزینهٔ سیاستِ ما». آزمونِ
  `test_no_report_number_depends_on_the_holdout_sensitivity_row` همین را نگهبانی می‌کند.
  دوباره است.

## این بازبینی چه چیزی را نمی‌گیرد

قاعده این است: هر عددِ گزارش باید در evidence «پیدا» شود. پس عددی که از فیلدی همسایه برداشته
شده قرمز نمی‌شود — اگر آستانهٔ اجرا `0.085` نوشته باشد و در جمله `0.09` بخوانید، همان گردکردنِ
مجاز است و می‌گذرد. این هم‌خانوادهٔ ریسکِ ۶ است: این ابزار برای تشخیصِ «دست‌نویس‌شدنِ عدد» ساخته نشده.
چیزی که واقعاً می‌گیرد، بدترین حالت است — عددی که هیچ اجرایی آن را ننوشته؛ و همان را جدی بگیرید.

## چه چیزی هرگز نباید بیاید

`cs-training.csv` و هر ردیفِ خامی؛ `config/credit.toml` اگر مسیرِ دیتابیسِ واقعیتان در آن است؛
`~/.pgpass` یا هر رمزِ رمزی (رمز فقط از محیط خوانده می‌شود و در هیچ فایلی که این ریپو ردیابی
می‌کند نوشته نمی‌شود)؛ و `.ipynb_checkpoints`.
