# شواهد اجرای واقعی

این پوشه خروجی یک اجرای کامل `solution.ipynb` روی `cs-training.csv` خودِ Kaggle است و تنها
منبع عددهای `report.md`.

| فایل | چه هست |
|---|---|
| `credit_evidence.json` | همهٔ عددها و نام‌هایی که نوت‌بوک اندازه گرفت؛ سلول آخر `report.md` را از همین پر کرد |
| `credit_run_manifest.json` | manifest بارگذاری: هش فایل ورودی، صفحه‌ها، قرنطینه، digest جدول |
| `run.txt` | فرمان‌ها و خروجی‌های همان اجرا: بارگذاری، زمان Run All، پیش‌بینی روی `cs-test.csv`، آزمون‌ها |

## به‌روزرسانی

بعد از یک Run All تازه، دو فایل JSON را بدون ویرایش از `data/curated/` کپی کنید:

```bash
cp data/curated/credit_evidence.json data/curated/credit_run_manifest.json docs/evidence/real/
```

و `run.txt` را با خروجی‌های همان اجرا بازنویسی کنید. دستی ویرایش‌کردن JSONها ممنوع است.

## چه چیزی را آزمون‌ها می‌سنجند

`ArchivedEvidenceConsistencyTests` بررسی می‌کند که manifest و evidence دربارهٔ یک فایل حرف
بزنند (هش، نام، تعداد ردیف = بارگذاری‌شده + قرنطینه)، که `report.md` هیچ جای‌نگهدار پرنشده‌ای
نداشته باشد، که هر عدد آن در evidence پیدا شود، و که holdout فقط با آستانهٔ انتخاب‌شده روی
validation قیمت‌گذاری شده باشد. محدودیت: این بررسی «وجود» است نه «منشأ»؛ عددی که از فیلد
همسایه کپی شود سبز می‌ماند.

دادهٔ خام، مدل ذخیره‌شده و فایل‌های قرنطینه هرگز اینجا نمی‌آیند.
